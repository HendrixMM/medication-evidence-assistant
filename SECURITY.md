# Security

Please do not open public issues for vulnerabilities or exposed credentials.

## Reporting

Use GitHub Security Advisories for private reports, or contact the repository owner directly.

## Local Secrets

- Keep real keys in `.env`.
- Use `.env.example` only for placeholders.
- Do not commit logs, caches, session dumps, or generated artifacts.

## Medical Safety

This project is an information assistant, not a clinical decision system. Changes that affect disclaimers, source attribution, guardrails, session replay, or API response contracts should include targeted tests.
